## 5. Design Direction

## 5.1 Visual Style

The site should avoid common AI-generated design patterns:

Avoid:

- Excessive gradients
- Generic glowing blobs
- Overused purple/blue AI color palettes
- Fake dashboard mockups everywhere
- Buzzword-heavy sections
- Too many animated cards
- Generic “Transform your business with AI” wording

Prefer:

- Editorial layout
- Strong typography
- Subtle grid
- Real project details
- Dark-neutral or warm-light theme
- Carefully spaced sections
- Minimal animations
- Clear case-study style project cards
- Human-written microcopy

Recommended aesthetic:

> Minimal editorial developer portfolio with premium agency feel.

---

## 5.2 Color Palette Options

### Option A — Premium Dark

- Background: `#0B0D10`
- Surface: `#111418`
- Text: `#F4F1EA`
- Muted Text: `#9CA3AF`
- Accent: `#D6A85C` or `#C9A227`
- Border: `rgba(255,255,255,0.08)`

Best for: premium, technical, serious brand.

### Option B — Warm Minimal Light

- Background: `#F7F3EA`
- Surface: `#FFFFFF`
- Text: `#171717`
- Muted Text: `#6B7280`
- Accent: `#1F3A5F`
- Border: `#E5E0D8`

Best for: human, clean, non-AI-looking portfolio.

### Recommended

Use **Option B** or a hybrid light-first design. It will look less AI-generated and more personal/editorial.

---

## 6. Typography

Recommended fonts:

- Headings: `Satoshi`, `General Sans`, `Inter Tight`, or `Neue Montreal`
- Body: `Inter`, `Geist`, or `Manrope`
- Code/technical labels: `JetBrains Mono` or `Geist Mono`

Typography should do most of the design work. Avoid heavy visual effects.

## 16. Content Tone Rules

### Do

- Write like a real technical person
- Be specific
- Mention real tools and outcomes
- Keep claims believable
- Use short paragraphs
- Show judgment and taste

### Don’t

- Use generic AI buzzwords
- Overpromise
- Write “revolutionize”, “unlock potential”, “cutting-edge” repeatedly
- Add fake metrics
- Use too many emojis
- Make every section sound like ChatGPT

## 18. Non-Functional Requirements

### Performance

- Lighthouse performance target: 90+
- Avoid heavy animation libraries unless necessary
- Use optimized fonts
- Compress images

### Accessibility

- Semantic HTML
- Proper heading hierarchy
- Visible focus states
- Alt text for meaningful images
- Good contrast ratio

### SEO

Required metadata:

- Title: `Umer Ali — AI Engineer & Full-Stack Developer`
- Description: `Umer Ali builds production-ready AI systems, agentic workflows, automations, and full-stack web applications using Next.js, Python, and FastAPI.`
- OG title/image
- Twitter card
- Canonical URL
